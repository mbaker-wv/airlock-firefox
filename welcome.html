Airlock

Use several accounts on the same site, side by side, without them getting mixed up.

A few quick steps

  1. Password saving Checking…

    Airlock turns this off for you, so Firefox can never fill in one account's password on another account's page.

  2. Turn off automatic work sign-in

    Firefox can sign you into your computer's work or school account by itself, in every tab, which defeats the point. Add-ons aren't allowed to change this, so please do it once: open Settings → Privacy & Security and uncheck “Allow Windows single sign-on for Microsoft, work, and school accounts”. If you don't see it, you're all set.

  3. Remove other container add-ons

    If you use something like Temporary Containers, it'll fight Airlock over new tabs. Open Add-ons and themes (⇧⌘A) and remove it.

  4. Pin the Airlock button

    Click the puzzle-piece icon in the toolbar, then the gear next to Airlock, then Pin to Toolbar.

How to use it

⌘T / Ctrl+TA new tab with a fresh, signed-out session
⌥⌘T / Ctrl+Alt+TA new tab in the same session, already signed in
Right-click a tab“New Tab in This Airlock” or “New Airlock Tab”
The Airlock buttonRename a session, keep it signed in, or forget it

Each session has its own color, shown under its tabs and in the address bar. When you close a session's last tab, its logins and site data are erased, unless you ticked Keep.

Tip: sign in once, then press ⌥⌘T to open other pages for the same account. They share that session's sign-in, so you won't be asked again.

Privacy

Airlock doesn't collect anything, doesn't track you, and never connects to the internet by itself. Everything it remembers stays in your Firefox. It asks to access all websites only so it can catch a page before it loads in Firefox's shared session and open it in its own airlock instead.
