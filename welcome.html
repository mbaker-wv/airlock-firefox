Airlock

Every tab is its own sealed session, so several accounts on the same site never mix.

Finish setup

  1. Password saving Checking…

    Airlock keeps Firefox from saving passwords, so it can never autofill one account's password into another.

  2. Turn off Microsoft single sign-on

    Firefox can sign you in with your computer's work account automatically, in every tab. Airlock isn't allowed to change this, so please do it once: open Settings → Privacy & Security and uncheck “Allow Windows single sign-on for Microsoft, work, and school accounts” (if you see it).

  3. Remove other container add-ons

    Add-ons like Temporary Containers also take over new tabs, and the two will fight. Open Add-ons and themes (⇧⌘A) and remove them.

  4. Pin the Airlock button

    Click the puzzle-piece icon in the toolbar, then the gear next to Airlock → Pin to Toolbar.

How to use it

⌘T / Ctrl+TNew tab in a brand-new airlock (a fresh, signed-out session)
⌥⌘T / Ctrl+Alt+TNew tab in the same airlock, already signed in
Right-click a tab“New Tab in This Airlock” or “New Airlock Tab”
Airlock buttonRename an airlock, keep it signed in, or forget kept ones

Each airlock has its own color, shown under its tabs and in the address bar. When an airlock's last tab closes, its cookies, logins and site data are erased, unless you ticked Keep.

Tip for Microsoft admins: sign into one portal, then press ⌥⌘T and open the others (Azure, Defender, Entra, Intune). They share the airlock's sign-in, so no extra MFA.

Privacy

Airlock collects no data and makes no network requests. Everything stays in your Firefox. It needs access to all websites only to move pages out of Firefox's shared default session into an airlock before they load.
